패치노트

v1.0.8

사진 저장소를 localStorage에서 IndexedDB로 분리해 고화질 사진을 불러올 때 발생하던 저장 용량 초과 문제를 개선했습니다. 기존 Base64 사진은 최초 실행 시 자동으로 IndexedDB로 이전하며, 전체 백업/복원에도 사진 저장소가 함께 포함됩니다. 기본 앱 테마 색상 설정을 추가했고 설정·모달 화면의 불필요한 가로 스크롤을 줄였습니다. 채팅 프로필 사진을 누르면 바로 친구 프로필을 볼 수 있으며 캐릭터 소개는 접기/펼치기를 지원합니다. 기념일·추억·즐겨찾기 메뉴를 정리하고, 시간 흐름 설정은 메시지 시간 표시 ON/OFF로 변경했습니다. 채팅 검색은 채팅방 안에서 바로 검색·이동할 수 있도록 변경했고 메시지 선택 삭제 기능을 추가했습니다. 채팅방 테마는 접어서 보관할 수 있으며 내 글자색·상대 글자색·시스템 문구 글자색도 변경할 수 있습니다. 채팅방 상단 고정 기능을 추가해 여러 방을 고정했을 때 가장 최근에 고정한 방이 가장 위에 표시됩니다. 기본 앱 화면의 상단/하단 바를 고정하고 뒤로가기 버튼 디자인도 개선했습니다.

v1.0.7

모바일 키보드가 올라오면 채팅 화면 높이를 visualViewport 기준으로 자동 조정해 입력창이 키보드 위에 유지되도록 개선했습니다. 채팅 상단 헤더와 하단 입력바는 메시지 스크롤과 분리해 고정되며, 입력바는 평소에도 살짝 위로 띄워 사용성을 높였습니다. 뒤로가기 버튼과 터치 영역도 키웠습니다. 또 친구별 이미지 생성용 ChatGPT 대화 URL을 추가해 캐릭터마다 전용 이미지 대화를 지정할 수 있습니다.

v1.0.6

Cloudflare/FLUX 및 이미지 API 자동 전환 기능을 제거했습니다. 사진 상황에서는 「📷 사진 보기」 카드가 나타나며, 누르면 캐릭터 외형·의상·현재 장면·최근 대화를 반영한 프롬프트를 자동 복사하고 설정한 ChatGPT 이미지 대화창을 엽니다. 생성한 사진은 「사진 가져오기」로 해당 카드 자리에 바로 넣을 수 있습니다. 메시지 자동 최하단 스크롤도 강화했고 하트/복사 버튼은 화면에서 제거했습니다.

v1.0.5

메시지 즐겨찾기 아이콘을 빈 하트(♡) / 채운 하트(♥) 방식으로 변경하고, 말풍선 전체 복사 버튼(⧉)과 같은 줄에 나란히 배치했습니다. 내 말풍선과 상대 말풍선 모두 동일하게 적용되며, 복사 성공 시 잠시 ✓ 표시가 나타납니다.

v1.0.3

말풍선 높이 및 이미지 겹침 문제를 구조적으로 수정했습니다. 채팅방별 내 말풍선, 상대 말풍선, 배경색 테마 설정을 추가했습니다. 안 읽은 메시지 굵게 표시와 개수 배지, 읽음 1 표시, 장기 기억 2.0, 추억 타임라인, 채팅 검색, 메시지 즐겨찾기, 현실 시간 인식, 친구 생활 패턴, 답장 속도 설정, 전체 데이터 백업/복원, 친구 삭제, UI 폰트와 채팅 폰트 개별 설정 기능을 추가했습니다. AI 이미지 생성 처리와 JSON 응답 오류 처리도 개선했습니다.

v1.0.2

전체 데이터 백업/복원, 친구 삭제, 채팅 데이터 보존 및 말풍선 관련 개선을 추가했습니다.

v1.0.1

친구 프로필, 사이드 메뉴, 채팅방 갤러리, 장기 기억 페이지, API 잠금 페이지 등을 추가했습니다.

v1.0.0

친구 관리, AI 채팅, 사진 전송, 캐릭터 설정 등 기본 AI 메신저 기능을 제공한 최초 버전입니다.
